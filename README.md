## Overview

Faceticket lets people enter an event or use a service by showing their face instead of a paper ticket or QR code. [what problem it solves: queues, ticket fraud, sharing of tickets, etc...]

> 📄 This project was published as a research paper: **[ FACETICKET: EXAM HALL AUTHENTICATION SYSTEM USING FACE BIOMETRICS]**, [India / IRCTC, March 2025].

## Features

- Feature 1, e.g. user registration with a face photo
- Feature 2, e.g. real-time face verification at the gate
- Feature 3, e.g. ticket / user management

## How it works

1. **Enrollment:** : The users are asked to take a live photo during registration.
2. **Verification:** : The users are asked to show their face to the camera in the venue
3. **Result:** : The system  checks the photo and the face in front of the camera, if it matches they are allowed
